# site-content

Контент сайта [gotogolang.github.io](https://gotogolang.github.io) /
[gotogo.pro](https://gotogo.pro) — упражнения, курсы и блог в формате Hugo Markdown.

---

## Концепция

Три раздела сайта:

| Раздел | URL | Назначение |
|--------|-----|------------|
| **Go!** | `/exercises/` | Практика: задачи с терминалом прямо в браузере |
| **dojo** | `/dojo/` | Теория: учебные курсы с упором на Go |
| **b!oG** | `/blog/` | Авторский блог: личный взгляд, заметки, разбор тем |

Названия обыгрывают симметрию: **b** и **d** — зеркальные буквы, **!** — общий элемент во всех трёх.

## Курсы (dojo)

### Go To Go!
Базовый курс для опытных программистов, впервые знакомящихся с Go.
Акцент на нативные типы и специфику языка, а не на общие концепции программирования.

Главы: Введение · Переменные и типы · Операторы и управление · Указатели · Массивы и срезы · Maps · Функции · Композитные типы · Дженерики

### Алгоритмы и структуры данных на Go
Практический курс по алгоритмам для тех, кто уже знает основы Go.

Главы: Анализ сложности · Сортировки · Поиск · Хеш-таблицы · Массивы · Списки · Очереди и стеки · Деревья · Графы

## Таксономия

В front matter страниц используются:

| Поле | Тип | Назначение |
|------|-----|------------|
| `series` | `["go-to-go"]` | Принадлежность к курсу; используется для навигации по серии |
| `tags` | `["types", "slices"]` | Темы для перекрёстных ссылок между курсами и упражнениями |
| `weight` | `10` | Порядок в главе (чем меньше, тем раньше) |

Пример front matter страницы курса:

```yaml
---
title: "Переменные и автовывод типов"
series: ["go-to-go"]
weight: 10
tags: ["variables", "types"]
---
```

## Шорткоды

### `{{</* terminal pack="go" exercise="id" */>}}`
Встраивает интерактивный терминал с упражнением. Используется в разделе Go!.

```md
{{</* terminal pack="go" exercise="go-func-01" */>}}
```

### `{{</* summary */>}}...{{</* /summary */>}}`
Блок TL;DR — краткое изложение темы для опытных читателей. Отображается зелёным
коллапсируемым блоком в начале раздела.

```md
{{</* summary */>}}
- `var x int` и `:=` объявляют переменные
- Go использует статическую типизацию с выводом типов
- Нулевое значение по умолчанию: `0`, `""`, `false`, `nil`
{{</* /summary */>}}

Подробное объяснение...
```

## Добавление упражнения (Go!)

1. Создать `content/exercises/go/{chapter}/{id}.md`
2. Front matter: `pack`, `exercise`, `difficulty`, `tags`
3. Вставить шорткод `{{</* terminal */>}}`
4. Добавить файлы задачи в репо `exercises`: `workspace/`, `check.sh`, `task.md`
5. Пуш → CI пересобирает сайт

## Добавление материала курса (dojo)

1. Создать файл в `content/dojo/{course}/chapter-XX/{NN-slug}.md`
2. Указать `series`, `weight`, `tags` в front matter
3. При необходимости использовать `{{</* summary */>}}` для TL;DR-блока
4. Пуш → CI пересобирает сайт
