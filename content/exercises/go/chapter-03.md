## Операторы

### Арифметические операторы

| Оператор | Описание      | Пример           |
|----------|---------------|------------------|
| `+`      | сложение      | `a + b`          |
| `-`      | вычитание     | `a - b`          |
| `*`      | умножение     | `a * b`          |
| `/`      | деление       | `a / b`          |
| `%`      | остаток       | `a % b`          |

Деление целых чисел — целочисленное: `7 / 2 == 3`. Для дробного результата нужны `float64`.

### Операторы увеличения и уменьшения

```go
i := 5
i++   // i == 6
i--   // i == 5
```

`++` и `--` в Go — операторы-инструкции, а не выражения. Их нельзя использовать в правой части присваивания: `j = i++` — ошибка компиляции. Префиксная форма (`++i`) отсутствует — только постфиксная.

### Присваивание и составные операторы

```go
x := 10
x += 5   // x == 15
x -= 3   // x == 12
x *= 2   // x == 24
x /= 4   // x == 6
x %= 4   // x == 2
```

### Операторы сравнения

| Оператор | Описание          |
|----------|-------------------|
| `==`     | равно             |
| `!=`     | не равно          |
| `<`      | меньше            |
| `<=`     | меньше или равно  |
| `>``     | больше            |
| `>=`     | больше или равно  |

Результат сравнения — `bool`. Сравнивать можно только значения одного типа.

### Логические операторы

| Оператор | Описание              |
|----------|-----------------------|
| `&&`     | логическое И          |
| `\|\|`   | логическое ИЛИ        |
| `!`      | логическое отрицание  |

`&&` и `||` — ленивые вычисления: правый операнд не вычисляется, если результат уже определён левым.

### Побитовые операторы

| Оператор | Описание            |
|----------|---------------------|
| `&`      | побитовое И         |
| `\|`     | побитовое ИЛИ       |
| `^`      | побитовое XOR       |
| `&^`     | AND NOT (bit clear) |
| `<<`     | сдвиг влево         |
| `>>`     | сдвиг вправо        |

```go
a := 0b1100
b := 0b1010

fmt.Println(a & b)   // 0b1000 = 8
fmt.Println(a | b)   // 0b1110 = 14
fmt.Println(a ^ b)   // 0b0110 = 6
fmt.Println(1 << 3)  // 8
fmt.Println(16 >> 2) // 4
```

### Приоритет операторов

От высшего к низшему:

```
*   /   %   <<  >>  &   &^
+   -   |   ^
==  !=  <   <=  >   >=
&&
||
```

При сомнениях используйте скобки — это делает намерения явными.

## Условные конструкции

### if / else

```go
if x > 0 {
    fmt.Println("положительное")
} else if x < 0 {
    fmt.Println("отрицательное")
} else {
    fmt.Println("ноль")
}
```

Фигурные скобки обязательны — даже для однострочных веток. Скобки вокруг условия не нужны.

**Инициализатор в `if`** — объявить переменную и сразу проверить её значение:

```go
if err := doSomething(); err != nil {
    fmt.Println("ошибка:", err)
}
// err здесь недоступна
```

Переменная из инициализатора видна только внутри блока `if/else`. Этот паттерн используется повсеместно при обработке ошибок в Go.

### switch

```go
switch day {
case "Monday", "Tuesday", "Wednesday", "Thursday", "Friday":
    fmt.Println("рабочий день")
case "Saturday", "Sunday":
    fmt.Println("выходной")
default:
    fmt.Println("неизвестный день")
}
```

В отличие от C/Java, `switch` в Go не требует `break` — каждый `case` завершается автоматически. Несколько значений в одном `case` разделяются запятой.

Чтобы «провалиться» в следующий `case`, используется `fallthrough`:

```go
switch n {
case 1:
    fmt.Println("один")
    fallthrough
case 2:
    fmt.Println("один или два")
}
```

**`switch` без выражения** — компактная альтернатива цепочке `if/else if`:

```go
switch {
case x < 0:
    fmt.Println("отрицательное")
case x == 0:
    fmt.Println("ноль")
default:
    fmt.Println("положительное")
}
```

## Циклы

В Go только один вид цикла — `for`. Он покрывает все три сценария.

### Классический for

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

### Цикл-while

```go
n := 1
for n < 100 {
    n *= 2
}
```

### Бесконечный цикл

```go
for {
    // выполняется бесконечно
    // выход — через break или return
}
```

### range

`range` перебирает коллекции: срезы, строки, карты, каналы.

```go
nums := []int{2, 4, 6, 8}

for i, v := range nums {
    fmt.Println(i, v)   // индекс и значение
}

for _, v := range nums {
    fmt.Println(v)      // только значение
}

for i := range nums {
    fmt.Println(i)      // только индекс
}
```

При переборе строки `range` возвращает пары (байтовый индекс, rune) — многобайтовые UTF-8 символы обрабатываются корректно.

### break и continue

```go
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue   // пропустить чётные
    }
    if i == 7 {
        break      // остановиться на 7
    }
    fmt.Println(i) // 1 3 5
}
```

**Метки** позволяют выйти из вложенного цикла:

```go
outer:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if i+j == 3 {
                break outer
            }
        }
    }
```

## defer

`defer` откладывает выполнение функции до возврата из текущей функции:

```go
func readFile(name string) {
    f, _ := os.Open(name)
    defer f.Close()   // выполнится при выходе из readFile

    // работа с файлом...
}
```

Несколько `defer` выполняются в порядке **LIFO** — последний зарегистрированный вызывается первым:

```go
func main() {
    defer fmt.Println("третий")
    defer fmt.Println("второй")
    defer fmt.Println("первый")
}
// вывод:
// первый
// второй
// третий
```

`defer` — стандартный паттерн для освобождения ресурсов: закрыть файл, разблокировать мьютекс, завершить транзакцию. Это надёжнее, чем вручную следить за всеми путями возврата из функции.

Аргументы отложенной функции вычисляются в момент регистрации `defer`, а не при вызове:

```go
x := 5
defer fmt.Println(x)   // напечатает 5, даже если x изменится
x = 10
```
