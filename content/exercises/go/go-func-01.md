Implement `Reverse(s string) string` — returns the string in reverse order.

**Examples:**
```
Reverse("hello")   → "olleh"
Reverse("")        → ""
Reverse("racecar") → "racecar"
```

Tests are in `solution_test.go`. Run `check` or `go test` to verify.
