## Объявление переменных

В Go есть два способа объявить переменную.

**Полная форма — `var`:**

```go
var name string
var age  int
var pi   float64 = 3.14159
```

**Короткое объявление — `:=`:**

```go
name := "Alice"
age  := 30
pi   := 3.14159
```

`:=` работает только внутри функций. `var` можно использовать как внутри функций, так и на уровне пакета.

Можно объявить несколько переменных сразу:

```go
var x, y, z int
a, b := 10, "hello"
```

## Именование и область видимости

Go требует `camelCase` для идентификаторов. Имена, начинающиеся с прописной буквы (`Name`), экспортируются из пакета и доступны снаружи. Имена со строчной буквы (`name`) — приватные.

Переменная видна в том блоке (фигурных скобках), где объявлена, и во всех вложенных блоках:

```go
func main() {
    x := 10          // видна в main
    if true {
        y := 20      // видна только внутри if
        fmt.Println(x, y)
    }
    // fmt.Println(y) — ошибка компиляции
}
```

Компилятор Go запрещает объявлять переменную и не использовать её — это частая ошибка у новичков.

## Примитивные типы

### Целочисленные типы

| Тип       | Размер          | Диапазон                                    |
|-----------|-----------------|---------------------------------------------|
| `int`     | 32 или 64 бита  | зависит от платформы                        |
| `int8`    | 8 бит           | −128 … 127                                  |
| `int16`   | 16 бит          | −32 768 … 32 767                            |
| `int32`   | 32 бита         | −2 147 483 648 … 2 147 483 647              |
| `int64`   | 64 бита         | −9.2×10¹⁸ … 9.2×10¹⁸                       |
| `uint`    | 32 или 64 бита  | 0 … (зависит от платформы)                  |
| `uint8`   | 8 бит           | 0 … 255                                     |
| `uint16`  | 16 бит          | 0 … 65 535                                  |
| `uint32`  | 32 бита         | 0 … 4 294 967 295                           |
| `uint64`  | 64 бита         | 0 … 1.8×10¹⁹                               |
| `uintptr` | 32 или 64 бита  | достаточно для хранения адреса памяти       |

`int`, `uint`, `uintptr` — размер зависит от целевой платформы (32 или 64 бита). Для большинства задач используйте `int` — это «естественный» целочисленный тип Go.

### Типы с плавающей точкой

| Тип       | Размер  | Точность   |
|-----------|---------|------------|
| `float32` | 32 бита | ~7 знаков  |
| `float64` | 64 бита | ~15 знаков |

По умолчанию используйте `float64` — большинство функций пакета `math` принимают именно его.

### Комплексные числа

| Тип          | Описание                               |
|--------------|----------------------------------------|
| `complex64`  | вещественная и мнимая часть — float32  |
| `complex128` | вещественная и мнимая часть — float64  |

```go
c := complex(3.0, 4.0)        // 3 + 4i
fmt.Println(real(c), imag(c)) // 3 4
```

### Булев тип

```go
var active bool = true
done := false
```

`bool` принимает ровно два значения: `true` и `false`. Целочисленные значения не преобразуются в `bool` неявно — в Go нет понятия «truthy/falsy».

### Строки

```go
greeting := "Hello, Go!"
empty    := ""
multi    := "первая строка\nвторая строка"
raw      := `путь: C:\Users\name`  // raw-строка, без escape
```

Строки в Go — неизменяемые последовательности байт в кодировке UTF-8. Конкатенация — оператором `+`. Длина в байтах — `len(s)`.

### Rune — символьный тип

`rune` — псевдоним для `int32`, представляет Unicode code point (один символ).

```go
r := 'А'               // тип rune, значение 1040
fmt.Println(string(r)) // "А"
```

Одинарные кавычки — для `rune`, двойные — для `string`.

При переборе строки через `range` Go автоматически декодирует байты в руны, корректно обрабатывая многобайтовые символы.

## Специальное значение nil

`nil` — нулевое значение для указателей, срезов, карт, каналов, функций и интерфейсов.

```go
var p *int       // p == nil
var s []int      // s == nil, len(s) == 0
```

`nil` не является «нулём» числового типа и не является пустой строкой — это отдельное значение для ссылочных типов.

## Нулевые значения

В Go каждый тип имеет **нулевое значение** — значение «по умолчанию» при объявлении без явной инициализации.

| Тип                                         | Нулевое значение |
|---------------------------------------------|------------------|
| `int`, `int8` … `int64`, `uint` …           | `0`              |
| `float32`, `float64`                        | `0.0`            |
| `complex64`, `complex128`                   | `0+0i`           |
| `bool`                                      | `false`          |
| `string`                                    | `""`             |
| указатели, срезы, карты, каналы, интерфейсы | `nil`            |

```go
var n int     // 0
var f float64 // 0.0
var s string  // ""
var b bool    // false
```

В Go нет понятия «неинициализированная переменная» — нулевые значения гарантированы компилятором.

## Преобразование типов

В Go нет неявных преобразований типов. Все преобразования — только явные:

```go
var i int     = 42
var f float64 = float64(i)
var u uint    = uint(f)
```

Попытка присвоить `int` в `float64` без явного преобразования — ошибка компиляции. Это намеренное решение: предотвращает скрытые потери точности и неожиданное поведение.

## Вывод типов

Компилятор Go выводит тип из правой части при коротком объявлении:

```go
i := 42           // int
f := 3.14         // float64
c := 0.5 + 1.5i   // complex128
s := "hello"      // string
b := true         // bool
```

Нетипизированные константы (числовые литералы) получают тип при первом использовании.

## Константы

Константы объявляются с `const` и вычисляются на этапе компиляции:

```go
const Pi      = 3.14159
const MaxSize = 1024
const Greeting = "Hello"
```

Несколько констант в блоке:

```go
const (
    StatusOK    = 200
    StatusNotFound = 404
)
```

**`iota`** — счётчик в `const`-блоке, автоматически инкрементируется с каждой строкой:

```go
const (
    Sunday = iota // 0
    Monday        // 1
    Tuesday       // 2
    Wednesday     // 3
)
```

Константы в Go «нетипизированы» до момента использования — одна числовая константа может участвовать в выражениях с разными числовыми типами без явного преобразования.
