## Что такое Go?

Go (неофициально — Golang) — компилируемый статически типизированный язык программирования, созданный в Google в 2007 году. Его авторы — Роберт Гризмер, Роб Пайк и Кен Томпсон: люди, создавшие Unix, UTF-8 и Plan 9. Первый публичный релиз состоялся в 2009 году, версия 1.0 вышла в 2012-м.

Язык появился как ответ на конкретные проблемы: медленная сборка больших C++ проектов, сложное управление конкурентностью, перегруженный синтаксис. Go создавался для промышленной разработки — быстрая компиляция, встроенная конкурентность, предсказуемый код.

С версии 1.0 язык развивается с гарантией обратной совместимости: код, написанный на Go 1.0, компилируется современным компилятором без изменений.

## Области применения

- **Серверные приложения и API** — стандартная библиотека содержит полноценный HTTP-сервер.
- **Инфраструктурные инструменты** — Docker, Kubernetes, Terraform, Consul написаны на Go.
- **Облачные сервисы** — Google, Cloudflare, Dropbox, HashiCorp используют Go в продакшне.
- **CLI-утилиты** — Go компилирует в маленькие статические бинарники без зависимостей.

## Ключевые особенности

**Компиляция в нативный код.** Нет виртуальной машины, нет интерпретатора. Программа компилируется напрямую в машинный код под целевую платформу.

**Сборщик мусора.** Управление памятью автоматическое, но с минимальными паузами — GC оптимизирован для серверных нагрузок.

**Горутины и каналы.** Конкурентность встроена в язык. Тысячи горутин занимают мегабайты памяти, в отличие от системных потоков.

**Строгая статическая типизация.** Ошибки типов обнаруживаются при компиляции, а не в рантайме.

**Один способ сделать.** В Go намеренно нет перегрузки функций, нет неявных преобразований, мало синтаксического сахара. Код предсказуем и читаем.

## Первая программа

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

Разберём построчно:

- `package main` — каждый Go-файл объявляет принадлежность к пакету. Пакет `main` — точка входа в исполняемую программу.
- `import "fmt"` — подключаем стандартный пакет форматированного ввода-вывода.
- `func main()` — функция `main` вызывается при запуске программы. Нет аргументов, нет возвращаемого значения.
- `fmt.Println(...)` — выводит аргументы в stdout с переводом строки.

## Среда разработки

Упражнения курса запускаются прямо в браузере — Go-контейнер, vim и gopls уже настроены.

Для локальной работы:
1. Скачать дистрибутив с [go.dev/dl](https://go.dev/dl/)
2. Проверить установку: `go version`

Рекомендуемые редакторы: **VS Code** с расширением Go (от Google) или **GoLand** (JetBrains).

## Компиляция и запуск

```
go run main.go            # скомпилировать и сразу запустить
go build main.go          # скомпилировать → бинарник ./main
go build -o app main.go   # бинарник с заданным именем
```

`go run` удобен при разработке — компилирует и запускает без промежуточных файлов.
`go build` создаёт бинарник для деплоя: один файл, нет зависимостей.

## Модули

Реальные проекты используют **модули** — систему управления зависимостями Go.

```
myapp/
├── go.mod        # имя модуля и зависимости
├── go.sum        # контрольные суммы зависимостей
└── main.go
```

Инициализировать модуль:
```
go mod init github.com/user/myapp
```

`go.mod` хранит имя модуля и минимальные версии зависимостей. `go.sum` — криптографические хэши для воспроизводимых сборок.
